# 表示言語

設定 → 見た目と相棒 → 表示言語で、日本語・英語・韓国語・中国語（簡体字）・スペイン語・タイ語・インドネシア語・ベトナム語を選択できます。

変更は即時反映され、`miomail-language` に保存されます。保存済みの言語が未対応、またはストレージが使用できない場合の初期表示は日本語です。タイ語の日付にもメール比較時の混乱を避けるため西暦を使用します。

## 翻訳の追加

- `src/renderer/lib/i18n.ts` の `languages` に言語 ID・自言語表記・地域表記・日付ロケールを追加します。
- `src/renderer/locales/` に辞書を追加し、`catalogs` に登録します。
- 日本語の原文をキーとし、英語辞書と同じキーと差し込み変数を用意します。翻訳が未登録のキーは英語、原文の順でフォールバックします。
- 表示時に `t('原文')` または `t('原文 {name}', { name })` を呼びます。モジュール初期化時に翻訳済みラベルを保存すると、言語変更が反映されないので避けてください。
- 文の一部だけを連結せず、差し込み変数を使って語順を変えられるようにします。

メール本文・件名・宛先・ユーザー独自のフォルダ名・MODメタデータ・サーバーの診断内容は翻訳しません。表示言語の切り替えで下書きや画面の入力状態をリセットしないでください。

## 確認

`npm run test:i18n` は辞書のキー、差し込み変数、明示的な翻訳呼び出しの網羅、言語保存、未対応値とストレージ障害時の動作、独自フォルダ名の保持を検証します。

`npm run build` に加え、画面上で言語変更と再読み込み、下書きの保持、長い翻訳の折り返しを確認してください。ネイティブのOSメニューと外部サーバー由来の診断メッセージは画面辞書の対象外です。
