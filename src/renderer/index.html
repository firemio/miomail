MioMail の画面が起動しませんでした

この画面の中のスクリプトが1行も動いていません。

枠(iframe)に入れて使っている場合、srcdoc も blob: も親と同じオリジンの URL も、 どれも親ページの Content-Security-Policy を引き継ぎます。この画面のスクリプトには MioMail 自身の nonce が付いているので、親の nonce とは一致せず全部止められます。

枠の外(親ページ)から、これを1回実行してください。 親ページ自身のスクリプトは信用されているので、そこから差し込めば動きます。 CSP の strict-dynamic が、信用されたスクリプトの差し込みを通す決まりだからです。 

const d = frame.contentDocument;
d.querySelectorAll('script[type="application/miomail-module"]')
  .forEach(function (el) {
    const s = d.createElement('script');
    s.type = 'module';
    s.textContent = el.textContent;
    d.head.appendChild(s);
  });

MioMail could not start: no script in this page ran. A framed document inherits the parent page's Content-Security-Policy, so the scripts in here never match its nonce. Run the snippet above from the parent page instead — a script inserted by code the parent already trusts is allowed by strict-dynamic.
