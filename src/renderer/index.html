枠(iframe)に入れて使っている場合、srcdoc も blob: も親と同じオリジンの URL も、 どれも親ページの Content-Security-Policy を引き継ぎます。この画面のスクリプトには MioMail 自身の nonce が付いているので、親の nonce とは一致せず全部止められます。

枠に入れる前に、親ページの nonce をこの HTML へ書き写してください。 nonce が合えば、この画面は自分で起動できます。sandbox をいじる必要も、 親から差し込む必要もありません。 

const mine = document.querySelector('script[nonce]').nonce;
const theirs = html.match(/'nonce-([a-f0-9]{32})'/)[1];
const fixed = html.split(theirs).join(mine);
